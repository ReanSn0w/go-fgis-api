## Что мы делаем?

Устраняем подтверждённые ошибки на коммите `fbd8538`: дубли объявлений, несовместимые контракты поиска, отсутствующие поля авторизации и отсутствующий публичный API жизненного цикла. За основу берём типизированный интерфейс из `registry.go` и `models.go`, который уже используется в README и тестах. В результате пакет должен собираться, выполнять запросы через единственную реализацию клиента и поддерживать заявленное обновление авторизации.

В задачу не входят новые фильтры поиска по товару, типизация сертификатов по догадкам, получение полной карточки, интеграция с ассистентом, публикация версии и обращения к реальному ФГИС. Неподтверждённые схемы запросов остаются явно обозначенными ограничениями.

## Для чего мы делаем?

В `client.go` сохранилась старая реализация, а `auth.go`, `registry.go`, README и тесты относятся к более полному интерфейсу. `go test ./...` останавливается на компиляции. Удаление повторных объявлений само по себе не восстановит пакет: новой авторизации нужны состояние клиента, настройки и управление фоновым циклом. Исправление должно восстановить согласованный контракт, не скрывая проблему удалением тестов или отключением новых файлов.
